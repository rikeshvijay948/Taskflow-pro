# Security Policy

## Supported Versions

We actively maintain the latest release of **Taskflow Pro** with security patches and performance fixes.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive data issue within this repository:

1. **Do not create public issues**: Please avoid disclosing vulnerabilities publicly on GitHub Issues.
2. **Contact the maintainer**: Email [rikeshvijay948@gmail.com](mailto:rikeshvijay948@gmail.com) with the subject `[SECURITY] Taskflow Pro Vulnerability Report`.
3. **Include details**: Provide steps to reproduce, sample payloads, and affected browser environments.
4. **Resolution**: All valid reports will be acknowledged within 48 hours and resolved promptly.

Thank you for helping keep Taskflow Pro secure!
